# `exiftool-xmp-absent.jpg`

**Producer:** ImageMagick 6.9 (`convert`), and nothing after it. Built by
[`sources/build_xmp_in_a_photograph.py`](../sources/build_xmp_in_a_photograph.py).

## What a person sees

The same flat blue-grey panel as
[`exiftool-xmp-history.jpg`](exiftool-xmp-history.md): 400 x 300, the word
`PRZYKLAD` in white.

## What is stored inside

No XMP packet. `convert` writes none of its own, so this is the picture with
the packet simply never added.

## Why this file exists

It is the control, and the finding it supports is silence. The reader must say
nothing about this file — not because nothing was found, but because there was
no packet to read, which the report states as its own remark rather than
leaving to be mistaken for a clean result.

A specimen that only ever fires proves a detector runs. It takes a file the
detector must stay quiet on to show the detector is *right*, and this is that
file.
