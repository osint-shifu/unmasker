# unmasker

Specimens live here and **are committed**, unlike the sibling project's corpus.
They are the test suite: a detector written against a hand-built fixture proves
nothing about a document a real producer wrote.

Each specimen should record, in a sibling `.md` file or in the test that uses it:

- which tool produced it and how
- what a human sees when it is opened
- what is actually in the file underneath

Only synthetic or clearly licensed material. Nothing from a real case.
